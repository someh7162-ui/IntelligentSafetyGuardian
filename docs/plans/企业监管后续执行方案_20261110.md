# 企业监管后续执行方案

基线日期：2026年11月10日。目标是为企业提供可验证的骑手安全监管原型，形成“发现事件—现场提醒—保存证据—上传记录—人工复核”的流程。本文件区分已经实现的软件、已经观察到的硬件状态和仍待验证的能力，不把模拟测试记为道路测试。

## 二 首期规则

### 急刹安全事件

设备固定于车把或车架，核对前向轴；当前默认+X。上电静置完成重力和陀螺仪零偏标定。初始试验阈值为纵向减速度达到3m/s²、持续200ms，结合颠簸及转弯过滤请求拍照，保留前后速度、定位有效性和传感器片段。急刹可能是合理避险，企业端不直接认定为违规。

### 超速累计

限速必须来自有效配置。有效且未过期的GNSS速度连续超过限速3秒后提醒；恢复到限速内持续5秒后结束该次事件。同一段持续超速只计一次，重复播报不增加次数。10分钟内达到3次才释放关联记录上传。GNSS失效时暂停判断并标记不完整事件，禁止用零速或旧坐标代替当前有效数据。

### 路口待复核

先配置固定试验路口，接近时触发短时连续快照，关联时间和有效位置。人工判断适用灯组、行驶方向、停止线和车辆通行过程；单张照片中出现红灯不能直接认定闯红灯。证据不完整时标记“证据不足”。旧模拟红灯预警与真实道路证据必须隔离。

## 三 分阶段执行

### P0 恢复可观察的本机链路

1. 保留旧程序备份，核对本次固件版本和实际接线。验证供电稳定，使用移动电源的稳压5V分路给主控和4G，保持共地；按电源模块实际输入/输出能力核验，不仅看5V跳帽。
2. 补齐企业版USB遥测、事件和照片报文，与现有Python网关及网页联调面板兼容；输出应有版本、长度、事件编号和定位有效性，不能让二进制照片混入文本解析。
3. 室外取得有效GNSS定位，验证约3秒遥测、地图首次定位自动聚焦、后续位置变化平滑跟随。明确坐标来源与地图坐标转换，防止重复转换或旧定位冒充实时位置。
4. 接入语音模块和扬声器，核对UART5 PC12/PD2、供电及TF卡文件。确认刹车与超速提醒可区分。

验收：网页可看到真实设备状态、有效/无效定位和事件照片；停止测试后串口释放，无后台自动传图。

### P1 打通独立4G正式接口

1. 核对当前4G接线USART3 PD8/PD9，与早期PC10/PC11方案区分；先查SIM、信号、注册和附着，再验证数据承载。
2. 验证超时、迟到应答、模块重启、串口错误和重连。只有收到OK不能代表SIM已就绪或已入网，应结合具体查询结果决定状态。
3. 为设备提供稳定HTTPS设备入口和独立凭证，凭证仅置于本机私有配置。当前服务器可用性需重新检查，不能沿用历史隧道地址作为永久入口。
4. 验证遥测、事件与JPEG接口，检查SAVED应答和事件编号幂等；错误或缺少凭证必须拒绝。测试期按需上传，完成后关闭业务通道。

验收：脱离Windows USB网关后仍能通过蜂窝网络上报；服务端和设备端编号可核对，超时重传不产生重复记录。

### P2 确认持久存储

1. 根据实际开发板原理图和器件丝印核对存储型号、总线及片选。0xFFFFFF只是本次未读到有效标识，不据此认定芯片不存在。
2. 先只读完整备份目标区域并计算摘要，核对空闲区与MCU身份；不擦除未知数据，不覆盖他人或旧固件内容。
3. 开放已确认区域后验证事件先落盘、照片分片、ACK后回收，以及写入各阶段断电恢复。当前RAM暂存仅保留最近照片，不具备断电保存能力。

验收：断网继续提醒和缓存，断电恢复后可补传；重复上传不重复保存，缓存满时有明确计数和处理策略。

### P3 完成企业复核流程

将急刹、超速累计组、路口待复核记录关联设备、骑手、时间、定位有效性和照片。支持确认、驳回和证据不足，保留审核人、时间及说明；模拟数据不进入真实统计。验证登录、设备凭证、照片权限、策略版本及重复事件处理。

### P4 固定安装道路测试

| 场景 | 需记录和核对的结果 |
|---|---|
| 正常减速、急刹 | 触发依据、照片时刻、前后速度、漏拍情况 |
| 过坑、转弯、搬动设备 | 是否错误触发，标定是否需要重做 |
| 持续超速、反复超速 | 单次边界、累计窗口、提醒与计次是否分离 |
| 无定位、定位过期 | 停止超速判断，网页明确显示无有效定位 |
| 断网、模块重启、掉电 | 恢复时间、积压数量、丢失与重复情况 |
| 试验路口 | 能否同时辨认相关信号灯、方向、停止线和通行过程 |

样本、原始日志与照片按试验编号在私有环境保存。测量完成后再计算识别或触发效果，不预填准确率、定位误差、流量和续航数值。

### P5 按证据决定升级摄像头及部署

先评估现有OV2640的640×480输出和对焦，再决定是否采购OV5640的DVP/JPEG适度广角版本。视角扩大与远处目标细节存在取舍，需比较同一距离的信号灯及道路画面。当前照片缓冲区和事件链路均有64KB限制，升级需同步评估外部帧缓存、分片、上传耗时和内存；不能只替换传感器名称。

模型通过独立FastAPI服务接入，先保留“识别未启用”模式。部署前重新检查端口、进程归属、数据库备份和服务器余量；不停止未授权服务、不占用他人GPU，不运行历史一键部署脚本。
