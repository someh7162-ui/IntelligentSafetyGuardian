# 后台管理系统详细设计

> **历史需求草案，旧接口与实时通信假设已取消。** 现行架构、功能边界和阶段以 [RiderGuard 当前实施方案](RiderGuard_当前实施方案.md) 为准；实际设备接口以 [RiderGuard 设备云端联调](RiderGuard_设备云端联调.md) 为准。本文件后文的 `/api/location/upload`、`/api/track/list`、`/api/risk/list` 和 MQTT/WebSocket 组合不作为实施或验收依据。

## 1. 系统概述

后台管理系统用于管理外卖骑手安全设备，实现：

-   实时监控
-   轨迹查看
-   风险管理
-   数据分析
-   AI报告查看

------------------------------------------------------------------------

# 3. 功能模块

## 3.1 首页大屏

展示：

-   在线设备数量
-   当前骑手数量
-   今日风险事件
-   安全趋势

------------------------------------------------------------------------

## 3.2 实时地图

功能：

-   显示骑手位置
-   显示运动轨迹
-   查看速度
-   查看风险等级

状态：

    绿色 正常

    黄色 注意

    红色 危险

------------------------------------------------------------------------

## 3.3 骑手管理

功能：

-   骑手信息管理
-   设备绑定
-   历史记录查询

字段：

    id
    name
    phone
    device_id
    status

------------------------------------------------------------------------

## 3.4 设备管理

管理：

-   在线状态
-   电量
-   GPS状态
-   摄像头状态

------------------------------------------------------------------------

## 3.5 风险事件管理

记录：

    事件类型

    发生时间

    位置

    速度

    图片

    AI分析结果

事件：

-   超速
-   路线偏离
-   人员密集
-   摔倒
-   碰撞

------------------------------------------------------------------------
