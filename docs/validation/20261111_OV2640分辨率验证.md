# OV2640分辨率调整记录

日期：2026年11月11日。用户连接硬件后，将企业监管本机联调固件的JPEG输出由320×240提高到640×480，实际烧录版本为2.0.2-local-vga。

## 修改与依据

- `Core/Inc/ov2640.h`记录当前输出尺寸640×480，照片缓冲区仍为64KB。
- `Core/Src/ov2640.c`增加VGA寄存器表，依据[ArduCAM官方OV2640参考驱动](https://github.com/ArduCAM/Arduino/blob/master/ArduCAM/ov2640_regs.h)中的`OV2640_640x480_JPEG`配置全传感器窗口及DSP缩放。
- 自动曝光/增益初始化保留分辨率位，只关闭彩条位，避免把新配置覆盖回旧模式。
- 企业固件增加仅供本机SWD使用的单次拍照入口，独立于事件编号、事件上传和持久存储；不会制造急刹或违规记录，也不自动反复拍摄。
- 原固件完整512KB备份和修改前源码保存在本机工作目录，未擦写外置Flash。

## 使用边界

- 输出总像素由76800增至307200，为原来的4倍；这不是传感器物理像素数增加，也不保证每个目标的可辨认细节提高4倍。
- 本次画面侧向朝向桌面和键盘；没有固定场景的前后对照，不能据此量化视野扩大、对焦改善或识别准确率。
- 分辨率影响图像细节，实际拍摄范围还受镜头、传感器取景窗口和安装朝向影响。应先朝前固定镜头并核对对焦，再进行道路画面对照。
- 当前场景照片约16KB，复杂画面可能更大。本次只验证640×480，不宣称更高分辨率在64KB缓冲下稳定。
- 采集流程仍有约1秒的轮询确认窗口，但等待期间主循环继续采样，并非阻塞IMU1秒。
- 4G业务上传和外置Flash写入保持关闭。三张实拍图仅存于本机，没有上传GitHub或服务器。
