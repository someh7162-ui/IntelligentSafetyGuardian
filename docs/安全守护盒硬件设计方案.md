# 安全守护盒硬件设计方案

> **架构状态：已取消，仅保留历史参考，不得作为采购、接线或开发依据。** 当前 V1 以 [RiderGuard 当前实施方案](RiderGuard_当前实施方案.md) 为准，采用 STM32F407 采集、骑行中约 3～5 秒一张 JPEG、4G 上传和云端 YOLO；本文件中的 Raspberry Pi 5 / RK3588 边缘 AI 方案不实施。

## 1. 项目目标

设计一款安装于外卖电动车上的一体式智能安全终端，实现：

-   实时定位
-   速度检测
-   环境感知
-   危险行为检测
-   数据上传
-   本地报警

设备采用云边协同架构，盒端负责实时采集和基础判断，服务器负责高级AI分析。

# 3. 核心硬件选型

## 3.1 主控板

推荐：

Raspberry Pi 5

功能：

-   Linux运行环境
-   摄像头处理
-   数据通信
-   AI轻量推理

后续产品化：

-   RK3588工业板

------------------------------------------------------------------------

## 3.2 摄像头模块

功能：

-   行人检测
-   道路识别
-   障碍物检测

要求：

-   广角
-   1080P
-   夜间适应

------------------------------------------------------------------------

## 3.3 GPS/GNSS模块

功能：

-   实时定位
-   速度获取
-   轨迹记录

输出：

    latitude
    longitude
    speed
    direction
    timestamp

## 3.4 IMU模块

功能：
