# 格式要求与现稿处理

依据用户提供的新文件夹内《15毕业设计模板20261019.doc》及模板审查记录整理。学校原件保存在[templates](templates/)；本文便于查阅，不替代原件。下面涉及“现稿处理”的内容属于本项目排版约定，不一概作为学校明文要求。

## 页面与正文

| 项目 | 模板明文要求或现稿处理 |
|---|---|
| 纸张与页边距 | A4；上下2.54cm，左右3.17cm |
| 页眉页脚距离 | 页眉1.5cm、页脚1.75cm；封面及声明页无页眉页脚 |
| 页码 | 正文至附录用阿拉伯数字连续编排；摘要和目录用罗马数字，页码居中 |
| 正文 | 中文宋体小四，西文Times New Roman，1.3倍行距，首行缩进2字符 |
| 正文段前段后 | 模板没有明确统一数值；现稿统一为0，避免人为增加段间空白 |
| 一级标题 | 黑体小二18pt，居中，2倍行距，段前段后自动 |
| 二级标题 | 黑体小三15pt，左对齐，2倍行距，段前段后各0.5行 |
| 三级标题 | 宋体四号14pt，左对齐，2倍行距，段前段后各0.5行 |
| 摘要 | 中英文内容对应；摘要正文小四、1.3倍行距、首行缩进2字符；关键词按模板处理 |

“段前段后0.5行”与“行距”是不同设置；现稿以行单位设置标题段间距。正文首行缩进不应继承到封面、公式或目录。

## 目录和参考文献

目录一级标题小四黑体，其余小四宋体，西文数字Times New Roman，1.3倍行距；一级顶格、二级缩进2字符、三级缩进4字符。

文献引用编号置于方括号内，普通引用按上标放在相关内容末尾；直接作为句子组成部分的文献编号按模板与正文对齐，不放在标题处。现稿16处正文引用采用上标并链接文末条目，文末编号可返回首次引用；目录107个标题均保留内部跳转。引用跳转是用户追加的导航需求，不是对学校模板原文的转述。

## 公式

模板要求使用Office原生公式编辑器，公式编号按章编排、置于行末右侧。原模板另有“首行缩进4个中文字符，不采用居中”的要求。

**用户随后明确要求公式主体居中。因此现稿9个公式采用主体居中、编号靠右的排版，该项是相对于学校原模板的明确差异。** 未修改原生公式内容；如学校最终要求严格按原模板，应由导师确认后统一调整，不能声称两种格式完全一致。

## 图表与附录

表序与表题放在表上方居中，模板要求五号黑体，推荐三线表；表内中文五号宋体、西文Times New Roman，保持单位清楚、表头与内容合理分页。图表按章编号，并在正文中引用；现稿保留原图、模块实物图与图题的关联。

关键代码、较长说明和辅助材料放附录，避免大量程序打断正文。代码摘录应与仓库提交和固件版本对应，不能含设备Token、服务器密码或地图安全配置。
