准备供电跳线时，从已测量确认的 5V 电源轨接到左侧第一对任一 5V 针，从 GND 轨接到左侧第三对任一 GND 针。保持断电先完成排针隔离/转接，再接电源。前三对中同一对的两针是同一网络，但后面的许多同排双针是不同 GPIO，不能据此把整条双排针直接插入同一五孔组。开发板离开面包板时使用公对母线；母端接开发板，公端接电源轨。上电前核对跳帽、输出电压、极性和无供电短接；避免外部 5V 与 USB 电源输出并接。

## 先处理双排插针问题

面包板同一编号行的 a–e 是一个电气网络，f–j 是另一个。不同信号针同时落入同一五孔组，会由面包板内部金属夹直接连在一起。把开发板整体跨在两块板之间，并不能自动隔离每侧双排引脚。

保持全部电源断开，取下开发板，保留/记录插入位置；用万用表检查原来相邻两排针对应的两个孔是否属于同一内部金属夹。若不同 GPIO 落入同一导通组，必须调整接法；外加跳线不能取消内部短接。

目前最容易实施的接法：开发板固定在绝缘支架/底板上，其公排针用公对母线引出，母端套开发板公针，公端插入目标面包板孔组。其他兼容的单排模块可以继续插在面包板上，孔组之间使用公对公线。需要让开发板本身直插时，应使用针序及尺寸匹配的隔离转接座；图中的转接座是方案示意，不是已经核实的现有配件。
