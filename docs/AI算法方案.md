# AI算法方案

## 1. AI系统目标

实现：

-   人员检测
-   道路识别
-   风险判断
-   异常分析

采用：

边缘AI + 云端大模型

------------------------------------------------------------------------

# 2. 视觉检测流程

    Camera

    ↓

    OpenCV

    ↓

    YOLO

    ↓

    目标检测

    ↓

    风险判断

------------------------------------------------------------------------

# 3. 人员密集检测

模型：

YOLO

检测：

    person
    bicycle
    vehicle

流程：

    图片

    ↓

    人数统计

    ↓

    距离估计

    ↓

    密度判断

    ↓

    风险等级

规则：

    人数少:
    LOW

    人数持续增加:
    MEDIUM

    大量人员:
    HIGH

------------------------------------------------------------------------

# 8. 云端大模型分析

大模型不部署在盒端。

流程：

    异常事件

    ↓

    上传图片和数据

    ↓

    VLM分析

    ↓

    生成解释

输入：

    图片

    速度

    位置

    人员数量

输出：

``` json
{
"risk":"high",
"reason":"人员密集且速度过快",
"suggestion":"减速"
}
```
